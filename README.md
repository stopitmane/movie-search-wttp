# Movie Search App

A simple web application that allows users to search for movies and save their favorite ones. The app uses the OMDb API to fetch movie data and provides users with the ability to view movie details, search for movies by title, and store favorite movies.

## Features

- Search for movies by title using the OMDb API.
- View movie details such as plot, actors, year, and more.
- Add and view favorite movies.
- Built with React and Tailwind CSS.
